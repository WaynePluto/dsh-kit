# 任务看板（task-board）

侧边栏「任务看板」面板：一个本地 Trello 式看板，替代外部看板工具的日常任务管理。

## 功能

- **卡片与列表的增删改**：列尾「添加卡片」、页头提示文字后的「添加列表」按钮（提交后
  新列落在板尾并自动滚动到位；不再占用板尾的虚线占位列）；点击卡片文本、卡片标题或列
  标题原地编辑（无弹窗，Escape 取消、失焦/Ctrl+Enter 保存）；卡片与列的删除按钮悬停可见，
  列删除为确认弹窗（官方 Modal，危险确认键）。
- **卡片标题**：位于卡片顶部「工作区 chip + 操作按钮」行与正文之间，字号比正文稍大，
  可点击自由编辑、可留空。它纯粹是给用户看的任务摘要，**不填入新对话**、也不进入复制文本。
- **卡片图片**：卡片操作行的回形针按钮可选择多张图片，焦点在卡片上时也可直接粘贴截图；
  缩略图行支持点击大图预览（官方 ImageLightbox）与悬停移除。仅接受 PNG / JPEG / WebP / GIF，
  单图 ≤ 4 MiB、单卡 ≤ 8 张、整板图片总量 ≤ 24 MB（超出会跳过并在页面状态行提示）。
  图片以自包含 data URL 随整份看板 JSON 落盘，没有独立的图片文件或孤儿文件。
- **清空最后一列**：只有最后一列显示「清空所有卡片」按钮（列顺序调整后跟随新的最后一列），
  点击后经确认弹窗删除该列全部卡片；空列时按钮禁用。
- **拖拽**：卡片可在列内排序、跨列拖动（悬停时其余卡片平滑滑开让位，拖到看板或列的
  边缘时自动滚动）；列标题栏是整列的横向拖拽手柄，可调换列顺序。拖拽中按 Escape 取消。
- **卡片左上角工作区 chip**：点击选择目标 dsh 工作区，不选时为「默认工作区」
  （填草稿时跟随 dsh 新会话的默认落点：当前 → 最近工作区）。
- **卡片右上角操作按钮**：置顶（横线+上箭头图标，点击把卡片移到当前列最上方，仅重排——
  后置顶的排最前，之前置顶的顺次下移；已是第一张则无操作）、添加图片、复制（复制卡片文本）、
  删除。
- **第一列卡片的发送按钮（右下角）**：在卡片所选的工作区新建对话，把任务文本填入
  该会话的输入框，并把卡片图片按官方附件契约登记成该会话的**图片草稿附件**
  （原生附件栏会显示缩略图，发送时由 dsh 自己编码进消息）。**不自动发送**——模型与
  思考强度留给你在新会话里现选，面板自动切回该会话；填入成功后卡片自动挪到
  **第二列首位**（待办 → 进行中；不足两列或发送失败时不移动）。卡片标题不参与回填。
  只有从左到右第一列的卡片显示发送按钮（拖动列顺序后，新的第一列获得发送按钮）。

## 数据与入口

- 数据是部署级个人数据：整份 JSON 存 `$DSH_HOME/dsh-kit/task-board.json`（与常驻服务
  注册表同目录），跨工作区共享，卸载套件后文件保留、重装即恢复。
- 浏览器半为乐观更新 + 400ms 防抖整份写回；写失败时页面顶部提示且不回滚本地操作。
- 面板入口：侧边栏「任务看板」行（排在插件、自动化任务、服务之后）。活动行再点一次
  回到当前会话由 panel-toggle 组件提供（上游原生行点击是无效重选）。

## 边界

- 不给模型注册 task 工具：看板是人的面板。
- 单板上限：16 列、每列 200 张、全板 2000 张、卡片 8000 字符、卡片标题 200 字符、
  列标题 80 字符；图片：单卡 8 张、单图 4 MiB、整板 data URL 总量 24 MB
  （越界写入被宿主半拒绝）。
- 图片填入新对话走官方 `conversation.createDrafts()` + `SessionInput.addAttachments()`
  （0.2.1-rc.5 契约，见 `docs/dsh/plugins.md`「程序化图片草稿附件」），不自建上传通道、
  不往会话写事件、不提交（发送留给用户）。
- 拖拽引擎 [@dnd-kit](https://github.com/clauderic/dnd-kit)（MIT，core 6.3.1 /
  sortable 10.0.0 / utilities 3.2.2，构建时内联进 `dist/client.js`，react/react-dom
  经页面冻结模块表共享单例）。

## 分发与管理

随 development-tools 组合包分发，套件安装后默认启用；可单独停用本组件行。
需要重装时，在 dsh「添加插件」中填写套件目录 `plugins/suite` 的绝对目录。
停用或卸载不会清理 `task-board.json`。
