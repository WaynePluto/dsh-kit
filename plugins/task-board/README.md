# 任务看板（task-board）

侧边栏「任务看板」面板：一个本地 Trello 式看板，替代外部看板工具的日常任务管理。

## 功能

- **卡片与列表的增删改**：列尾「添加卡片」、看板尾「添加列表」；点击卡片文本或列标题
  原地编辑（无弹窗，Escape 取消、失焦/Ctrl+Enter 保存）；卡片与列的删除按钮悬停可见，
  列删除为两步确认（先点一次变红，再点一次生效）。
- **拖拽**：卡片可在列内排序、跨列拖动（悬停时其余卡片平滑滑开让位，拖到看板或列的
  边缘时自动滚动）；列标题栏是整列的横向拖拽手柄，可调换列顺序。拖拽中按 Escape 取消。
- **卡片左上角工作区 chip**：点击选择目标 dsh 工作区，不选时为「默认工作区」
  （发送时跟随 dsh 新会话的默认落点：当前 → 最近工作区）。
- **卡片右上角复制按钮**：复制卡片文本；卡片右上角另有删除按钮。
- **第一列卡片的发送按钮（右下角）**：在卡片所选的工作区新建对话，把任务文本填入
  输入框并立即发送；面板自动切回该会话。只有从左到右第一列的卡片显示发送按钮
  （拖动列顺序后，新的第一列获得发送按钮）。

## 数据与入口

- 数据是部署级个人数据：整份 JSON 存 `$DSH_HOME/dsh-kit/task-board.json`（与常驻服务
  注册表同目录），跨工作区共享，卸载套件后文件保留、重装即恢复。
- 浏览器半为乐观更新 + 400ms 防抖整份写回；写失败时页面顶部提示且不回滚本地操作。
- 面板入口：侧边栏「任务看板」行（排在插件、自动化任务、服务之后）。活动行再点一次
  回到当前会话由 panel-toggle 组件提供（上游原生行点击是无效重选）。

## 边界

- 不给模型注册 task 工具：看板是人的面板。
- 单板上限：16 列、每列 200 张、全板 2000 张、卡片 8000 字符、列标题 80 字符
  （越界写入被宿主半拒绝）。
- 拖拽引擎 [@dnd-kit](https://github.com/clauderic/dnd-kit)（MIT，core 6.3.1 /
  sortable 10.0.0 / utilities 3.2.2，构建时内联进 `dist/client.js`，react/react-dom
  经页面冻结模块表共享单例）。

## 分发与管理

随 development-tools 组合包分发，套件安装后默认启用；可单独停用本组件行。
需要重装时，在 dsh「添加插件」中填写套件目录 `plugins/suite` 的绝对目录。
停用或卸载不会清理 `task-board.json`。
