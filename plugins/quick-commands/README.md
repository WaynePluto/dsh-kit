# 快捷指令

`@dsh-kit/dsh-plugin-quick-commands` 在聊天输入框左下角的工具排（`[+]`、权限与计划按钮
之后）加一枚按钮，点开一个悬浮面板：里面是用户自定义的快捷指令列表，点击一条就把该
文本插入输入框**光标位置**（不发送、不替换已有草稿）。指令可新增、编辑、删除。

## 使用

- 输入框左下角按钮（列表笔图标）开/关面板。
- 点击指令行：文本插入当前光标处，面板关闭。可以先把光标点到正文中间再点指令——
  点击输入框本体不会关闭面板。
- 新增：底部输入框输入后回车；行尾悬浮出编辑（铅笔）与删除（垃圾桶）按钮，
  编辑回车提交、Escape 取消；删除立即生效。
- 方向键在指令行之间移动，回车插入聚焦行，Escape 关面板；输入框内方向键仍移动光标。
- 指令数据存 `$DSH_HOME/dsh-kit/quick-commands.json`（部署级，同一 home 所有工作区
  共享；上限 100 条、单条 2000 字符）。每次改动立即整份写回，写失败面板顶部亮错误、
  本地改动保留。

## 边界

- 插入失败（草稿在捕获后又被并发修改）会自动重试一次；仍失败经 Toast 提示，面板不关。
- 停用组件后按钮与面板消失，已保存的指令文件保留。
- 面板打开时点击任何面板外位置（输入框本体、会话区、侧栏）都会关闭面板；要插入到
  正文中间时，先点好光标再重新打开面板点指令（编辑器会记住光标位置）。
