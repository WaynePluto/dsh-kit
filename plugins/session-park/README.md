# 切屏停靠

`@dsh-kit/dsh-plugin-session-park` 解决「运行中的会话不在视野里，结束时没有绿点」：
两类「人已离开会话视图」的信号都会把主视图让给当前工作区的一个空白会话（官方
「新建会话」同一条路径），之后会话结束时侧栏行正常亮起「完成未读」绿点：

- **切屏离开**：离开 dsh 窗口（失焦或最小化）持续 3 秒、且当前会话还在运行；
- **面板接管**：点击侧栏面板菜单项（插件/自动化任务/服务/任务看板，以及「更多」
  菜单里的面板项）把主视图换成面板页时，若当前会话还在运行，立即停靠并把面板
  选回来——面板页保持在你眼前，底下已换成空白会话。

点击会话行回到原会话，绿点清除。

## 为什么需要

上游只有在会话结束时「不在主视图（mainView）」才记完成未读（`SessionStatus.
completionUnread`，上游注释原话 "observed stop outside the main view"）。你正停留的
会话就是主视图，它结束时不记未读；面板页挡住时也一样（`layout.selectPanel` 只切
面板、不清 mainView）。于是在多个工作区都有任务时：你停在 A 会话等它跑完、切屏去
干别的或转去看服务面板——A 结束没有绿点，你回来看到别的工作区有绿点就去看了别人，
A 的结果被错过。本组件在「人已离开会话视图」时用纯官方导航动作满足这个判定的
前提，不改变上游未读机制。

## 行为与边界

### 切屏离开

- 出发信号是**窗口失焦或隐藏**（alt-tab 只触发 blur，最小化两者都触发），持续
  **3 秒**且到点时复查「仍离开、会话仍在运行」才停靠：快速 alt-tab 拿个东西、
  失焦后 3 秒内会话恰好结束，都不会动作。
- 停靠动作每个离开周期最多一次；停靠后主视图停在空白会话上（不在运行），再次
  切屏不会重复动作。回来后该干嘛干嘛，组件**不做**「回来自动切回」——自动切回
  会立刻清掉绿点，与初衷相悖。

### 面板接管

- 触发是**面板选中**（侧栏面板行与「更多」菜单项都经官方 `layout.selectPanel`，
  也覆盖任何程序化打开面板的路径），当前会话运行中即停靠，无去抖——点击菜单项
  是明确的导航意图，会话视图已被面板页替换，「不知道自己在哪个会话」从这一刻
  开始。
- 停靠落地的瞬间官方导航会把面板切回会话视图（`startSession` 的 reveal 语义），
  组件在**同一次同步通知内**把面板选回来：发生在 React 提交渲染之前，面板页不
  重挂、无闪烁。
- 停靠后再点该面板行回会话（panel-toggle）或点会话行，落在空白会话上——与切屏
  停靠「不自动切回」同一状态；原会话结束后侧栏行亮绿点。
- 已知边界：停靠在途（一次 blank 复用/创建 RPC，通常几毫秒）时用户点开 blank
  会话行或点「新建会话」，恢复面板的判据（main 已是 blank）无法区分，会把面板
  选回来——再点一次即可，无数据影响。
- 停靠在途时的任何换面板/回会话操作都会让上游放弃这次停靠（`layout.selectPanel`
  abort 挂起导航），不会与人抢导航。

### 共同

- 停靠落点是**当前会话所在工作区**的空白会话（复用既有 blank，与原生新建会话
  完全同路径，不会堆积会话）；输入框草稿跟随会话，停靠不丢草稿。
- **待操作（黄点，审批/计划确认/提问）期间不停靠**：黄点不会自动消失、需要用户
  回答才清除（官方 `uiSession.sessionStatus` 快照的 `pendingInteraction`），停靠
  只会把要操作的会话从眼前换走；答完题会话继续运行，再切走按新一轮正常停靠。
- 运行中（蓝点）状态点上游不做主视图过滤、恒显示，停靠不会让你错过它。
- 设置页（设置按钮）不在触发范围：它是设置 shell/modal，不经过 `selectPanel`、
  不换 main 视图。
- 当前视图是子代理会话、或没有主视图会话时，判定为不在运行，不动作。
- 全程官方 Context service（`layout` / `sessions` / `uiSession` / `uiWorkspace`），
  零 DOM 注入、无宿主服务、无设置项；想临时不用在插件详情停用本组件行即可。

## 维护与验证

```powershell
pnpm --filter @dsh-kit/dsh-plugin-session-park test
```

纯浏览器半、无宿主服务；构建落盘后由官方 client-hmr 自动热替换（宿主半无改动、
组件行已装载时无需重启 dsh）。依赖的 `layout.panelInfo` / `layout.selectPanel`、
`uiSession.adapter.current`、`uiSession.sessionStatus`（黄点判定）、`sessions.list`
与 `uiWorkspace.startSession` 都是公开契约，上游变更风险低；完成未读机制的出处与
复核要点见 docs/dsh/workspace.md「完成未读的精确机制」，面板导航契约见
docs/dsh/plugins.md「全局面板」。

## 分发与管理

本包不作为独立安装项分发，而是 `@dsh-kit/dsh-plugin-conversation-enhancements`
（会话增强 Bundle）的组件。停用后行为恢复原生（切屏不再停靠），安装、卸载和升级
以整个 Bundle 为单位。套件安装后本组件默认启用；需要重装时，在 dsh「添加插件」
中填写套件目录 `plugins/suite` 的绝对目录。
