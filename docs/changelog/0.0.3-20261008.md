# 0.0.3-20261008（2026-10-08）

预发布版本；下一个正式版本为 0.0.3。

## 网页搜索开关

- 新增第 21 个功能组件「网页搜索开关」（独立分发包）：为 dsh 官方「网页搜索」
  插件补充停用与恢复开关——官方插件页这一项只是一张配置卡片，没有提供开关
- 使用入口：插件 → 已安装 → 网页搜索开关，点开卡片即见「官方网页搜索」开关
- 停用机制与 dsh 原生插件行开关完全同一（官方 `pluginManager` 服务写入 profile
  用户层补丁），不是第二套插件管理器；热加载可用时立即生效，需要重启时给出
  「已写入配置，重启 dsh 后生效」提示，生效后自动消失
- 停用后 dsh 正常启动，重启后官方「网页搜索」设置卡片自动消失，重新启用后恢复；
  卸载本插件不会自动恢复官方网页搜索，恢复方法见插件 README
- 新装的 dsh-station 默认安装并启用；已安装用户配套升级时自动补装（此前卸载过
  该包的用户不受影响）

## Windows 安装包记住上次安装目录

- 修复重装/升级时目录页永远回到 Program Files 默认值的问题：安装时把实际目录
  写入卸载注册表 `InstallLocation`，下次安装目录页默认回显该路径
- 兼容旧版本（≤0.0.2 未记录路径）：自动从已注册的卸载程序路径反推上次安装目录；
  本次修复从下个安装包起生效，现有安装的路径在首次升级时被记录
